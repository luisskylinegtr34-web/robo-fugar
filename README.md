# 🤖 Robô Fuga

Jogo arcade feito com **HTML, CSS e JavaScript** puro, sem bibliotecas. Desvie dos obstáculos, pegue as estrelas e faça combos pra bater o recorde!

## ▶️ Jogue agora

👉 https://luisskylinegtr34-web.github.io/robo-fugar/

## 🎮 Como jogar

- **Celular:** toque na metade esquerda ou direita da tela pra trocar de pista
- **Computador:** use as setas ← → (ou as teclas A e D)
- Desvie de ☄️ 🪨 👾
- Pegue as ⭐ em sequência pra aumentar o **combo**
- O escudo 🛡️ aguenta uma batida
- A velocidade aumenta com o tempo

## ✨ Recursos

- Gráficos desenhados em `<canvas>`
- Partículas, tremida de tela e efeitos sonoros (Web Audio API)
- Combo e multiplicador de pontos
- Recorde salvo no navegador (`localStorage`)
- Funciona no celular e no computador

## 🛠️ Tecnologias

HTML5 · CSS3 · JavaScript · Canvas API · Web Audio API

## 💻 Rodar localmente

Baixe o `index.html` e abra no navegador. Não precisa instalar nada.
